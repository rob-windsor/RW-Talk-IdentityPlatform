# Introduction to the Microsoft Identity Platform and Entra ID

The Microsoft identity platform is a cloud identity service that enables you to build applications that sign in users using their Microsoft identities or social accounts. It authorizes access to your APIs or Microsoft APIs like Microsoft Graph. This session will introduce you to the Microsoft identity platform and cover topics including Entra ID app registration, permissions and consent, tokens, authentication, and authentication flows.
